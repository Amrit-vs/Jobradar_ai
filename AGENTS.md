# JobRadar AI contribution rules

1. Prefer small, incremental changes.
2. Never implement fake external APIs or bypass anti-bot or authentication protections.
3. Respect source terms, robots.txt, rate limits, and applicable policies.
4. Never hard-code credentials or automatically submit job applications.
5. Keep job-source integrations behind adapters and matching independent of sources.
6. Keep frontend and backend responsibilities separate.
7. Write tests for important business logic; tests must not depend on live sites.
8. Document assumptions and run relevant tests after meaningful changes.
9. Prefer maintainability over cleverness; do not rewrite working architecture unnecessarily.
